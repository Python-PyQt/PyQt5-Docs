The :sip:ref:`~PyQt5.QtXml.QDomText` class represents text data in the parsed XML document.

You can split the text in a :sip:ref:`~PyQt5.QtXml.QDomText` object over two :sip:ref:`~PyQt5.QtXml.QDomText` objecs with :sip:ref:`~PyQt5.QtXml.QDomText.splitText`.

For further information about the Document Object Model see Level 1 and Level 2 Core. For a more general introduction of the DOM implementation see the :sip:ref:`~PyQt5.QtXml.QDomDocument` documentation.
