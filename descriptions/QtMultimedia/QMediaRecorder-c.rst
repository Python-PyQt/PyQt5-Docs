The :sip:ref:`~PyQt5.QtMultimedia.QMediaRecorder` class is used for the recording of media content.

The :sip:ref:`~PyQt5.QtMultimedia.QMediaRecorder` class is a high level media recording class. It's not intended to be used alone but for accessing the media recording functions of other media objects, like :sip:ref:`~PyQt5.QtMultimedia.QRadioTuner`, or :sip:ref:`~PyQt5.QtMultimedia.QCamera`.
