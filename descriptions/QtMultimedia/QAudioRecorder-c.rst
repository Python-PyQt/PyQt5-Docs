The :sip:ref:`~PyQt5.QtMultimedia.QAudioRecorder` class is used for the recording of audio.

The :sip:ref:`~PyQt5.QtMultimedia.QAudioRecorder` class is a high level media recording class and contains the same functionality as :sip:ref:`~PyQt5.QtMultimedia.QMediaRecorder`.

.. literalinclude:: ../../../snippets/qtmultimedia-src-multimedia-doc-snippets-multimedia-snippets-media.py
    :lines: 215-224

In addition :sip:ref:`~PyQt5.QtMultimedia.QAudioRecorder` provides functionality for selecting the audio input.

.. literalinclude:: ../../../snippets/qtmultimedia-src-multimedia-doc-snippets-multimedia-snippets-media.py
    :lines: 228-237

The `Audio Recorder Example <https://doc.qt.io/qt-5/qtmultimedia-multimedia-audiorecorder-example.html>`_ shows how to use this class in more detail.
