The :sip:ref:`~PyQt5.QtMultimedia.QCamera` class provides interface for system camera devices.

:sip:ref:`~PyQt5.QtMultimedia.QCamera` can be used with QCameraViewfinder for viewfinder display, :sip:ref:`~PyQt5.QtMultimedia.QMediaRecorder` for video recording and :sip:ref:`~PyQt5.QtMultimedia.QCameraImageCapture` for image taking.

You can use :sip:ref:`~PyQt5.QtMultimedia.QCameraInfo` to list available cameras and choose which one to use.
