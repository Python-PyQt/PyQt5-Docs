A :sip:ref:`~PyQt5.QtMultimedia.QCamera.FrameRateRange` represents a range of frame rates as minimum and maximum rate.

If the minimum frame rate is equal to the maximum frame rate, the frame rate is fixed. If not, the actual frame rate fluctuates between the minimum and the maximum.

.. seealso:: :sip:ref:`~PyQt5.QtMultimedia.QCamera.supportedViewfinderFrameRateRanges`, :sip:ref:`~PyQt5.QtMultimedia.QCameraViewfinderSettings`.
