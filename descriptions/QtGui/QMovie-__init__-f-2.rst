Constructs a :sip:ref:`~PyQt5.QtGui.QMovie` object. :sip:ref:`~PyQt5.QtGui.QMovie` will use read image data from *fileName*. If *format* is not empty, :sip:ref:`~PyQt5.QtGui.QMovie` will use the image format *format* for decoding the image data. Otherwise, :sip:ref:`~PyQt5.QtGui.QMovie` will attempt to guess the format.

The *parent* object is passed to :sip:ref:`~PyQt5.QtCore.QObject`'s constructor.
