Sets the page size to *size*. *size* is specified in millimeters.

If the size matches a standard :sip:ref:`~PyQt5.QtGui.QPagedPaintDevice.PageSize` then that page size will be used, otherwise :sip:ref:`~PyQt5.QtGui.QPagedPaintDevice.PageSize.Custom` will be set.
