The :sip:ref:`~PyQt5.QtGui.QNativeGestureEvent` class contains parameters that describe a gesture event.

Native gesture events are generated by the operating system, typically by interpreting touch events. Gesture events are high-level events such as zoom or rotate.

+----------------------------+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------+
| Event Type                 | Description                     | Touch sequence                                                                                                                                   |
+============================+=================================+==================================================================================================================================================+
| Qt::ZoomNativeGesture      | Magnification delta in percent. | `macOS <https://doc.qt.io/qt-5/qtwebengine-platform-notes.html#macos>`_: Two-finger pinch.                                                       |
+----------------------------+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------+
| Qt::SmartZoomNativeGesture | Boolean magnification state.    | `macOS <https://doc.qt.io/qt-5/qtwebengine-platform-notes.html#macos>`_: Two-finger douple tap (trackpad) / One-finger douple tap (magic mouse). |
+----------------------------+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------+
| Qt::RotateNativeGesture    | Rotation delta in degrees.      | `macOS <https://doc.qt.io/qt-5/qtwebengine-platform-notes.html#macos>`_: Two-finger rotate.                                                      |
+----------------------------+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------+

In addition, BeginNativeGesture and EndNativeGesture are sent before and after gesture event streams:

BeginNativeGesture ZoomNativeGesture ZoomNativeGesture ZoomNativeGesture EndNativeGesture

.. seealso:: Qt::NativeGestureTypeQGestureEvent.
