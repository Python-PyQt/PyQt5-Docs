Returns the page size of the page layout.

Note that the :sip:ref:`~PyQt5.QtGui.QPageSize` is always defined in a Portrait orientation. To obtain a size that takes the set orientation into account you must use :sip:ref:`~PyQt5.QtGui.QPageLayout.fullRect`.
