This enum represent standard key bindings. They can be used to assign platform dependent keyboard shortcuts to a QAction.

Note that the key bindings are platform dependent. The currently bound shortcuts can be queried using :sip:ref:`~PyQt5.QtGui.QKeySequence.keyBindings`.
