The :sip:ref:`~PyQt5.QtGui.QPictureIO` class contains parameters for loading and saving pictures.

:sip:ref:`~PyQt5.QtGui.QPictureIO` contains a :sip:ref:`~PyQt5.QtCore.QIODevice` object that is used for picture data I/O. The programmer can install new picture file formats in addition to those that Qt provides.

You don't normally need to use this class; :sip:ref:`~PyQt5.QtGui.QPicture.load`, :sip:ref:`~PyQt5.QtGui.QPicture.save`.

.. seealso:: :sip:ref:`~PyQt5.QtGui.QPicture`, :sip:ref:`~PyQt5.QtGui.QPixmap`, :sip:ref:`~PyQt5.QtCore.QFile`.
