The :sip:ref:`~PyQt5.QtGui.QOpenGLContextGroup` class represents a group of contexts sharing OpenGL resources.

:sip:ref:`~PyQt5.QtGui.QOpenGLContextGroup` is automatically created and managed by :sip:ref:`~PyQt5.QtGui.QOpenGLContext` instances. Its purpose is to identify all the contexts that are sharing resources.

.. seealso:: :sip:ref:`~PyQt5.QtGui.QOpenGLContext.shareGroup`.
