Returns the list of document formats supported by :sip:ref:`~PyQt5.QtGui.QTextDocumentWriter`.

By default, Qt can write the following formats:

+-----------+---------------------------+
| Format    | Description               |
+===========+===========================+
| plaintext | Plain text                |
+-----------+---------------------------+
| HTML      | HyperText Markup Language |
+-----------+---------------------------+
| ODF       | OpenDocument Format       |
+-----------+---------------------------+

.. seealso:: :sip:ref:`~PyQt5.QtGui.QTextDocumentWriter.setFormat`.
