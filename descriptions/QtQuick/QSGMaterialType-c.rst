The :sip:ref:`~PyQt5.QtQuick.QSGMaterialType` class is used as a unique type token in combination with QSGMaterial.

It serves no purpose outside the QSGMaterial::type() function.

**Note:** All classes with QSG prefix should be used solely on the scene graph's rendering thread. See `Scene Graph and Rendering <https://doc.qt.io/qt-5/qtquick-visualcanvas-scenegraph.html#scene-graph-and-rendering>`_ for more information.
