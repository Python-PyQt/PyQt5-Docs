The :sip:ref:`~PyQt5.Qt3DExtras.QExtrudedTextGeometry` class allows creation of a 3D extruded text in 3D space.

The :sip:ref:`~PyQt5.Qt3DExtras.QExtrudedTextGeometry` class is most commonly used internally by the QText3DMesh but can also be used in custom :sip:ref:`~PyQt5.Qt3DRender.QGeometryRenderer` subclasses.
