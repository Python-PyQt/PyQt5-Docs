This enum describes the types of action which can be performed on the web page.

Actions only have an effect when they are applicable. The availability of actions can be be determined by checking isEnabled() on the action returned by :sip:ref:`~PyQt5.QtWebEngineWidgets.QWebEnginePage.action`.
