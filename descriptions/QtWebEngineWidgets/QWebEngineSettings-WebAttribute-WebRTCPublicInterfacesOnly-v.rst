Limits `WebRTC <https://doc.qt.io/qt-5/qtwebengine-features.html#webrtc>`_ to public IP addresses only. When disabled `WebRTC <https://doc.qt.io/qt-5/qtwebengine-features.html#webrtc>`_ may also use local network IP addresses, but remote hosts can also see your local network IP address. Disabled by default. (Added in Qt 5.11)
