The formatting options define how the URL is formatted when written out as text.

Note that the case folding rules in Nameprep, which :sip:ref:`~PyQt5.QtCore.QUrl` conforms to, require host names to always be converted to lower case, regardless of the Qt::FormattingOptions used.

The options from QUrl::ComponentFormattingOptions are also possible.

.. seealso:: QUrl::ComponentFormattingOptions.
