This enum provides shorter names for the keyboard modifier keys supported by Qt.

**Note:** On `macOS <https://doc.qt.io/qt-5/qtwebengine-platform-notes.html#macos>`_, the ``CTRL`` value corresponds to the Command keys on the keyboard, and the ``META`` value corresponds to the Control keys.
