If the :sip:ref:`~PyQt5.QtCore.QXmlStreamReader.tokenType` is :sip:ref:`~PyQt5.QtCore.QXmlStreamReader.TokenType.StartElement`, this function returns the element's namespace declarations. Otherwise an empty vector is returned.
