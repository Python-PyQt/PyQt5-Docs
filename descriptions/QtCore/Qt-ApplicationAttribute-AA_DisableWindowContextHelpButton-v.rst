Disables the :sip:ref:`~PyQt5.QtCore.Qt.WindowType.WindowContextHelpButtonHint` by default on :sip:ref:`~PyQt5.QtCore.Qt.WindowType.Sheet` and :sip:ref:`~PyQt5.QtCore.Qt.WindowType.Dialog` widgets. This hides the **?** button on Windows, which only makes sense if you use QWhatsThis functionality. This value was added in Qt 5.10. In Qt 6, :sip:ref:`~PyQt5.QtCore.Qt.WindowType.WindowContextHelpButtonHint` will not be set by default.
