The :sip:ref:`~PyQt5.QtCore.QStateMachine.WrappedEvent` class inherits :sip:ref:`~PyQt5.QtCore.QEvent` and holds a clone of an event associated with a :sip:ref:`~PyQt5.QtCore.QObject`.

A wrapped event is generated by a :sip:ref:`~PyQt5.QtCore.QStateMachine` in response to a Qt event. The :sip:ref:`~PyQt5.QtCore.QEventTransition` class provides a transition associated with a such an event. :sip:ref:`~PyQt5.QtCore.QStateMachine.WrappedEvent` is part of `The State Machine Framework <https://doc.qt.io/qt-5/statemachine-api.html>`_.

The :sip:ref:`~PyQt5.QtCore.QStateMachine.WrappedEvent.object` function returns the object that generated the event. The :sip:ref:`~PyQt5.QtCore.QStateMachine.WrappedEvent.event` function returns a clone of the original event.

.. seealso:: :sip:ref:`~PyQt5.QtCore.QEventTransition`.
