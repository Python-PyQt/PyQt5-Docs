Sets the serialization byte order to *bo*.

The *bo* parameter can be :sip:ref:`~PyQt5.QtCore.QDataStream.ByteOrder.BigEndian` or :sip:ref:`~PyQt5.QtCore.QDataStream.ByteOrder.LittleEndian`.

The default setting is big endian. We recommend leaving this setting unless you have special requirements.

.. seealso:: :sip:ref:`~PyQt5.QtCore.QDataStream.byteOrder`.
