The :sip:ref:`~PyQt5.QtCore.QMetaMethod` class provides meta-data about a member function.

A :sip:ref:`~PyQt5.QtCore.QMetaMethod` has a :sip:ref:`~PyQt5.QtCore.QMetaMethod.methodType`, a methodSignature(), a list of :sip:ref:`~PyQt5.QtCore.QMetaMethod.parameterTypes` and :sip:ref:`~PyQt5.QtCore.QMetaMethod.parameterNames`, a return :sip:ref:`~PyQt5.QtCore.QMetaMethod.typeName`, a :sip:ref:`~PyQt5.QtCore.QMetaMethod.tag`, and an :sip:ref:`~PyQt5.QtCore.QMetaMethod.access` specifier. You can use :sip:ref:`~PyQt5.QtCore.QMetaMethod.invoke` to invoke the method on an arbitrary :sip:ref:`~PyQt5.QtCore.QObject`.

.. seealso:: :sip:ref:`~PyQt5.QtCore.QMetaObject`, :sip:ref:`~PyQt5.QtCore.QMetaEnum`, :sip:ref:`~PyQt5.QtCore.QMetaProperty`, `Qt's Property System <https://doc.qt.io/qt-5/properties.html>`_.
