Constructs a :sip:ref:`~PyQt5.QtCore.QLoggingCategory` object with the provided *category* name. All message types for this category are enabled by default.

If *category* is ``0``, the category name is changed to ``"default"``.

Note that *category* must be kept valid during the lifetime of this object.
