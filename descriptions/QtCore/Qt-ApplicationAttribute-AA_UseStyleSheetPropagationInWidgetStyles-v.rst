By default, Qt Style Sheets disable regular :sip:ref:`~PyQt5.QtWidgets.QWidget` palette and font propagation. When this flag is enabled, font and palette changes propagate as though the user had manually called the corresponding :sip:ref:`~PyQt5.QtWidgets.QWidget` methods. See `The Style Sheet Syntax - Inheritance <https://doc.qt.io/qt-5/stylesheet-syntax.html#inheritance>`_ for more details. This value was added in Qt 5.7.
