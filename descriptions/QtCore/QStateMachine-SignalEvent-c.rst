The :sip:ref:`~PyQt5.QtCore.QStateMachine.SignalEvent` class represents a Qt signal event.

A signal event is generated by a :sip:ref:`~PyQt5.QtCore.QStateMachine` in response to a Qt signal. The :sip:ref:`~PyQt5.QtCore.QSignalTransition` class provides a transition associated with a signal event. :sip:ref:`~PyQt5.QtCore.QStateMachine.SignalEvent` is part of `The State Machine Framework <https://doc.qt.io/qt-5/statemachine-api.html>`_.

The :sip:ref:`~PyQt5.QtCore.QStateMachine.SignalEvent.sender` function returns the object that generated the signal. The :sip:ref:`~PyQt5.QtCore.QStateMachine.SignalEvent.signalIndex` function returns the index of the signal. The :sip:ref:`~PyQt5.QtCore.QStateMachine.SignalEvent.arguments` function returns the arguments of the signal.

.. seealso:: :sip:ref:`~PyQt5.QtCore.QSignalTransition`.
