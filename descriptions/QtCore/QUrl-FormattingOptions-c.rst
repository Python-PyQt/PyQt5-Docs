The :sip:ref:`~PyQt5.QtCore.QUrl.FormattingOptions` class is a set of flags whose values are the members of the :sip:ref:`~PyQt5.QtCore.QUrl.UrlFormattingOption`, :sip:ref:`~PyQt5.QtCore.QUrl.ComponentFormattingOption` and :sip:ref:`~PyQt5.QtCore.QUrl.ComponentFormattingOption` enums. Instances of the class support the standard Python ``int`` methods.
