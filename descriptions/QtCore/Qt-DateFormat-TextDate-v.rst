The default Qt format, which includes the day and month name, the day number in the month, and the year in full. The day and month names will be short, localized names. This is basically equivalent to using the date format string, "ddd MMM d yyyy". See :sip:ref:`~PyQt5.QtCore.QDate.toString` for more information.
