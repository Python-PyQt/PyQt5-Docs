Returns the number corresponding to the month of this date, using the following convention:

* 1 = "January"

* 2 = "February"

* 3 = "March"

* 4 = "April"

* 5 = "May"

* 6 = "June"

* 7 = "July"

* 8 = "August"

* 9 = "September"

* 10 = "October"

* 11 = "November"

* 12 = "December"

Returns 0 if the date is invalid.
