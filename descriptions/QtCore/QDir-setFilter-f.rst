Sets the filter used by :sip:ref:`~PyQt5.QtCore.QDir.entryList` and :sip:ref:`~PyQt5.QtCore.QDir.entryInfoList` to *filters*. The filter is used to specify the kind of files that should be returned by :sip:ref:`~PyQt5.QtCore.QDir.entryList` and :sip:ref:`~PyQt5.QtCore.QDir.entryInfoList`. See :sip:ref:`~PyQt5.QtCore.QDir.Filter`.
