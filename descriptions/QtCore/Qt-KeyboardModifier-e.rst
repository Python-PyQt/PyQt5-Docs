This enum describes the modifier keys.

**Note:** On `macOS <https://doc.qt.io/qt-5/qtwebengine-platform-notes.html#macos>`_, the ``ControlModifier`` value corresponds to the Command keys on the keyboard, and the ``MetaModifier`` value corresponds to the Control keys. The ``KeypadModifier`` value will also be set when an arrow key is pressed as the arrow keys are considered part of the keypad.

**Note:** On Windows Keyboards,  and :sip:ref:`~PyQt5.QtCore.Qt.Key.Key_Meta` are mapped to the Windows key.
