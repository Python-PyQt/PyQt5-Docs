This is an overloaded function.

Sets the codec for accessing INI files (including ``.conf`` files on Unix) to the :sip:ref:`~PyQt5.QtCore.QTextCodec` for the encoding specified by *codecName*. Common values for ``codecName`` include "ISO 8859-1", "UTF-8", and "UTF-16". If the encoding isn't recognized, nothing happens.
