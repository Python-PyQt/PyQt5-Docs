Overrides the reported network accessibility. If *accessible* is :sip:ref:`~PyQt5.QtNetwork.QNetworkAccessManager.NetworkAccessibility.NotAccessible` the reported network accessiblity will always be :sip:ref:`~PyQt5.QtNetwork.QNetworkAccessManager.NetworkAccessibility.NotAccessible`. Otherwise the reported network accessibility will reflect the actual device state.
