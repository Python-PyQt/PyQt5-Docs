The :sip:ref:`~PyQt5.QtNetwork.QDnsServiceRecord` class stores information about a DNS SRV record.

When performing a lookup on a service, zero or more records will be returned. Each record is represented by a :sip:ref:`~PyQt5.QtNetwork.QDnsServiceRecord` instance.

The meaning of the fields is defined in RFC 2782.

.. seealso:: :sip:ref:`~PyQt5.QtNetwork.QDnsLookup`.
