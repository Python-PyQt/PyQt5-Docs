The :sip:ref:`~PyQt5.QtNetwork.QDnsTextRecord` class stores information about a DNS TXT record.

When performing a text lookup, zero or more records will be returned. Each record is represented by a :sip:ref:`~PyQt5.QtNetwork.QDnsTextRecord` instance.

The meaning of the fields is defined in RFC 1035.

.. seealso:: :sip:ref:`~PyQt5.QtNetwork.QDnsLookup`.
