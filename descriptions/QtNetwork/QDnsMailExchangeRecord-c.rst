The :sip:ref:`~PyQt5.QtNetwork.QDnsMailExchangeRecord` class stores information about a DNS MX record.

When performing a lookup on a service, zero or more records will be returned. Each record is represented by a :sip:ref:`~PyQt5.QtNetwork.QDnsMailExchangeRecord` instance.

The meaning of the fields is defined in RFC 1035.

.. seealso:: :sip:ref:`~PyQt5.QtNetwork.QDnsLookup`.
