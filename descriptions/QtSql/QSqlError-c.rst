The :sip:ref:`~PyQt5.QtSql.QSqlError` class provides SQL database error information.

A :sip:ref:`~PyQt5.QtSql.QSqlError` object can provide database-specific error data, including the driverText() and :sip:ref:`~PyQt5.QtSql.QSqlError.databaseText` messages (or both concatenated together as :sip:ref:`~PyQt5.QtSql.QSqlError.text`), and the :sip:ref:`~PyQt5.QtSql.QSqlError.nativeErrorCode` and :sip:ref:`~PyQt5.QtSql.QSqlError.type`.

.. seealso:: :sip:ref:`~PyQt5.QtSql.QSqlDatabase.lastError`, :sip:ref:`~PyQt5.QtSql.QSqlQuery.lastError`.
