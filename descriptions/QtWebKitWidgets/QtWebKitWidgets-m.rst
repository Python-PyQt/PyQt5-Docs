.. sip:module-description::
    :status:    done
    :brief:     A WebKit1 based web browser (deprecated)

The :sip:ref:`~PyQt5.QtWebKitWidgets` module contains classes that implement a
WebKit1 based web browser for use in :sip:ref:`~PyQt5.QtWidgets` based
applications.

The module is deprecated.  The corresponding C++ library is no longer part of
Qt.
