The :sip:ref:`~PyQt5.Qt3DCore.QNodeCommand` class is the base class for all :sip:ref:`~PyQt5.Qt3DCore.ChangeFlag.CommandRequested` QSceneChange events.

The :sip:ref:`~PyQt5.Qt3DCore.QNodeCommand` class is the base class for all QSceneChange events that have the changeType() :sip:ref:`~PyQt5.Qt3DCore.ChangeFlag.CommandRequested`.

You can subclass this to create your own node update types for communication between your QNode and QBackendNode subclasses when writing your own aspects.
