Encapsulates geometry.

A :sip:ref:`~PyQt5.Qt3DRender.QGeometry` class is used to group a list of :sip:ref:`~PyQt5.Qt3DRender.QAttribute` objects together to form a geometric shape Qt3D is able to render using :sip:ref:`~PyQt5.Qt3DRender.QGeometryRenderer`. Special attribute can be set in order to calculate bounding volume of the shape.
