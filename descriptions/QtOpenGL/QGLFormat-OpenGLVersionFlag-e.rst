This enum describes the various OpenGL versions that are recognized by Qt. Use the :sip:ref:`~PyQt5.QtOpenGL.QGLFormat.openGLVersionFlags` function to identify which versions that are supported at runtime.

See also http://www.opengl.org for more information about the different revisions of OpenGL.
