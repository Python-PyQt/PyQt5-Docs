Specifies that :sip:ref:`~PyQt5.QtOpenGL.QGLContext.bindTexture` should try to generate mipmaps. If the GL implementation supports the ``GL_SGIS_generate_mipmap`` extension, mipmaps will be automatically generated for the texture. Mipmap generation is only supported for the ``GL_TEXTURE_2D`` target.
