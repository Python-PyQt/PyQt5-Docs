.. sip:module-description::
    :status:    done
    :brief:     Classes for rendering OpenGL in traditional widgets (deprecated)

The :sip:ref:`~PyQt5.QtOpenGL` module contains classes that allow the use of
OpenGL in rendering 3D graphics in :sip:ref:`~PyQt5.QtWidgets` based
applications.

The module is deprecated.  The OpenGL classes in :sip:ref:`~PyQt5.QtGui` should
be used instead.
