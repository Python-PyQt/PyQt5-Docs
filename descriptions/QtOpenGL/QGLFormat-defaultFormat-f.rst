Returns the default :sip:ref:`~PyQt5.QtOpenGL.QGLFormat` for the application. All :sip:ref:`~PyQt5.QtOpenGL.QGLWidget` objects that are created use this format unless another format is specified, e.g. when they are constructed.

If no special default format has been set using :sip:ref:`~PyQt5.QtOpenGL.QGLFormat.setDefaultFormat`, the default format is the same as that created with :sip:ref:`~PyQt5.QtOpenGL.QGLFormat`.
