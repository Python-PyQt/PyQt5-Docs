Support for Old Versions of Python
==================================

When a Python version reaches it's end-of-life, it will become unsupported
in the next release of PyQt5.  For example, if the current version of PyQt5
is v5.15.x then it will become unsupported in v5.15.x+1.

*Unsupported* means that those versions of Python may still work but are
untested.
